# 艾菲拉地圖 v2 編輯與連線管理

正式網站目錄維持不變。原圖 assets/ephyra-base.png 保留，新版 assets/ephyra-bible-v2.png。新圖使用內建 imagegen 依原圖編輯；新增第四層露天高樓與覆蓋孢室區、橋路及外緣樹林，維持左蘑丘右後聖樹、四層古城、牛皮紙墨水、無文字／路線／穩定器建築的要求。

- canon.js 是 build-canon.cjs 從已合併 WORLD_BIBLE.md 單向產生的地圖／事件摘錄。不要手改；命令：node build-canon.cjs <本機Bible檔>。來源正文不複製到公開庫。
- data.js 配置來源 ID、地域設備實例與顯示關係，不增寫世界設定。四座穩定器均引用 TEC-001。群息之庭 GEO-011 在第四層眠孢庭 GEO-005。
- layout.js 保存圖像、座標、字標位置與折線。兩座位置未定的設備用 placementPending 顯示，標記可自由移動；第一層附近的遺構設備点不是已定精確樓層。
- 分層：road 已確認旅程但路形示意；life 魔素網路功能；structure 同一生物體；story 修復先後。地域包含只用 parent，不畫成輸送線。禁止從 life 推定可行走，禁止從相鄰層推定直達道路。
- 現在顯示功能關係總覽，未硬編碼所有時期皆封鎖／皆開放；網路、實體路線、進入許可應按事件另行管理。
- 白域仍是獨立空白頁；第四層裂隙點明標位置意向／事件示意，不新增為永久正典入口。
- 故事 items 使用永久 eventId、previous、next；按鏈呈現，不按 EVT 數字排序。EVT-013、018、019、020 保留獨立區，未擅定完整銜接。
- 圖面可替換圖片、拖曳節點、匯出與載入版本2 JSON。旧版層位已過時，版本1拒絕載入並說明，不悄悄把舊第二層位置套給新群息之庭。
- 標題／指南針、地名／符號、孢室素材、路線獨立圖層。手動改圖使用相同1536×1024坐標系即可。

每次 Bible 更新後：重建 canon → 檢查 ID、層級、关系及故事鏈差異 → 重對座標 → 瀏覽器驗收 → 發布。Drive A 與 Bible 有新差異先提出，不把提案反寫 Bible。檢查指令 node check-bible.cjs；互動需另測縮放、手機、位置匯出入與白域切頁。
