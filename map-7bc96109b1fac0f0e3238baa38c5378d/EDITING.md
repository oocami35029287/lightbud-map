# 艾菲拉地圖的圖層與手動修改

此目錄是地圖唯一正式來源。底圖與文字、節點、路線分開，修改底圖不會把標註烙進圖片。

## 原圖

`assets/ephyra-base.png` 是採用的牛皮紙墨水底圖，1536 × 1024 像素，不含文字或節點。請先下載另存副本，用你習慣的繪圖工具修改。保持畫布尺寸與地形位置時，現有標註可直接沿用；修改構圖後可重新對位。Git 歷史保留已提交的底圖版本。

網站的「替換底圖」可載入新 PNG/JPEG/WebP 預覽，調整位置、寬度、透明度。「恢復原底圖」會回到正式圖片。載入的圖片只在本次瀏覽使用，關閉頁面不會保存，必須另存圖片檔。

## 可編輯圖層

- `layout.js`：底圖路徑與尺寸、場所座標、標籤偏移、路線轉折點。座標沿用原圖像素，左上角為 (0,0)。
- `data.js`：場所內容、來源、歸屬、菌路／道路及封鎖狀態。原有 ID 應保持不變。
- `index.html` 的 `#decorations`：獨立 SVG 標題「艾菲拉」、指南針與白域框，可編輯位置、文字和向量線條。
- `assets/spore-chamber.png`：透明孢室地標，透過 `index.html` 的 `#landmarks` 另層疊在第二層。可自行換圖或調整該 image 的 x/y/width/height；底圖原檔不受影響。
- `app.js`：獨立繪製場所符號、地名和線路，底圖不會被改寫。
- `style.css`：文字、符號、介面配色。

右側台地是北方；指南針表達大致方位，斜俯視圖並非測繪比例。白域置於圖外框內，並非艾菲拉的一塊陸地。場所歸屬不自動產生道路。具體穩定器與待決場所的圖上座標屬示意，不代表新世界觀決策。

目前四層由下往上編號。空心之芽在第二層孢室；四層各有關卡節點，詳細操作待設計。第一層通路未定案，沒有自行接出必經路。聖樹底部的穩定器遺跡完全被樹覆蓋、不可進入；教團單純信仰守護，未進入且不知內情。沉韻之庭沿地下建築結構間的孢絲延伸至聖樹根部，這段菌路仍封鎖。

## 拖曳對位與保存

1. 載入你修改後的底圖。
2. 展開「調整場所位置」，開啟拖曳編輯；所有場所會顯示。
3. 拖曳場所符號或地名。路線端點會跟隨，原有中途轉折點保留。
4. 匯出 `ephyra-layout.json` 並保存，之後可載入繼續修改。此檔包含位置、標籤偏移、路線轉折點及底圖尺寸配置，不包含圖片本身。
5. 更細的標籤偏移或路線彎折可編輯 JSON 的 `labelDx/labelDy`（螢幕像素）與 `routes`（原圖像素），再載入檢查。

瀏覽器中的修改不會直接寫回 GitHub。正式發布時，把圖片放回 `assets/`（可用新檔名保留舊圖），將匯出的 `placements/routes/background` 整合到 `layout.js`，只提交此網站目錄；GitHub Pages 更新同一網址。不要提交私密管理文件或本機暫存資料。
